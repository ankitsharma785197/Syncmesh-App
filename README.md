# 🚀 Overview

**SyncMesh** is a privacy-first productivity application that lets you instantly sync clipboard and transfer files between your Android phone and desktop devices over your local network.

No account.

No internet.

No cloud.

No tracking.

Everything stays inside your own Wi-Fi or Hotspot.

Built for speed, privacy and seamless cross-device productivity.

# ⚙️ Quick Setup

## 1. Install

- Install SyncMesh on your Android device.
- Install the desktop application on Windows or macOS.

---

## 2. Connect

Connect both devices to the same:

- Wi-Fi Network

or

- Mobile Hotspot

---

## 3. Pair Devices

Choose any pairing method:

- QR Code
- Manual Pairing
- Nearby Devices

---

## 4. Enable SyncMesh Keyboard

Clipboard synchronization requires enabling the SyncMesh Keyboard.

Android Settings

↓

Languages & Input

↓

Keyboard

↓

Enable **SyncMesh Keyboard**

↓

Set it as your default keyboard.

---

## 5. Complete Onboarding

The first launch includes:

- Interactive Onboarding
- Product Tour
- Feature Introduction

You can replay the Product Tour anytime from Settings.

---

## 6. Start Using SyncMesh

You can now:

- Copy clipboard across devices
- Transfer files
- Manage paired devices
- View clipboard history
- Monitor transfers

Everything works completely offline.

# 🧠 How It Works

SyncMesh establishes secure peer-to-peer communication using your local network.

Technologies used:

- TCP (Reliable Data Transfer)
- UDP (Device Discovery)
- Local Peer-to-Peer Communication

No external servers are involved.

Your data never leaves your local network.
